# ASCII 小猫样式总览（展示）

> 说明：本文件用于展示"可能出现的角色样式"，便于快速预览。  
> 实际是否出现由 `scripts/update_readme.py` 的事件判定逻辑决定。

## 1) 主小猫基础表情

```text
 /\_/\
( -.- ) zZ
 / >~
```

```text
 /\_/\
( ^.^ )
 / >♪
```

```text
 /\_/\
( o.o )
 / >!!
```

```text
 /\_/\
( >.< )
 / >~!
```

## 2) 主小猫叠加样式

### 帽子（streak）

```text
 /\🧢/\
( ^.^ )
 / >~
```

```text
 /\🎩/\
( ^.^ )
 / >~
```

```text
 /\👑/\
( ^.^ )
 / >~
```

### 眼睛饰品（accessories）

> 眼睛饰品叠加在基础表情之上，与状态眼睛逻辑独立，优先级：alien > 深夜 > 白天

```text
( 👀 )   ← 深夜提交（睡眼惺忪）
```

```text
( 😎 )   ← 白天提交超过一半（戴墨镜）
```

```text
( 👽 )   ← 当天提交数为质数（外星猫彩蛋）
```

### 手持物

> 按语言优先级匹配 emoji；若所用语言不在列表则直接显示语言名称

```text
 / >~ 🐍   ← Python
 / >~ 🔌   ← LabVIEW
 / >~ 🐹   ← Go
 / >~ 🦀   ← Rust
 / >~ JavaScript   ← 其他语言（直接显示名称）
```

### 活跃节奏

```text
☀️  ⛈️  ☁️
```

## 3) 多小猫角色（活动猫）

> 每种活动猫拥有专属眼睛

```text
 /\_/\
( *.* )   ← Review猫（专注审查）
 / 🔍
```

```text
 /\_/\
( ^.^ )   ← Merge猫（开心合并）
 / 🚩
```

```text
 /\_/\
( ★.★)   ← Star猫（闪光之眼）
 / ⭐
```

```text
 /\_/\
(o.o )   ← Fork猫（好奇张望）
 / 🌿
```

```text
 /\_/\
( >.< )   ← 讨论猫（激动发言）
 / 📢
```

```text
 /\_/\
( -.- )   ← Wiki猫（安静写文档）
 / 📘
```

## 4) 非猫角色

> 非猫角色不再绘图，直接以单行 `[图标]："语句"` 显示在小猫脚底

```text
🐭："Fix that!"
```

```text
🐧："Linux vibes"
```

```text
🐙："Multi-branch"
```

```text
🦊："Reviewed your PR"
```

```text
🐝："Rapid commits"
```

## 5) 彩蛋角色

> 彩蛋小猫在脚底显示 1-2 词提示原因

```text
 /\_/\
(★.★)
 / [★]
(1200 commits)   ← 里程碑
```

```text
 /\_/\
( ^.^ )
 / 🎉
(已 merge)   ← 当天合并 PR ≥2
```

```text
 /\_/\
( ._. )
 / 👻
(罕见彩蛋)   ← 概率 1%
```

```text
 /\🧢/\ 🎂
( ^.^ )
 / >~
```

> 注：生日蛋糕 aura 附加在帽子/耳朵之后（如同时有帽子则为 `/\🧢/\ 🎂`）
