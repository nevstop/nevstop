# ASCII 小猫样式总览（展示）

> 说明：本文件用于展示“可能出现的角色样式”，便于快速预览。  
> 实际是否出现由 `scripts/update_readme.py` 的事件判定逻辑决定。

## 1) 主小猫基础表情

```text
 /\_/\
( -.- ) zZ
 / >~
```

```text
 /\_/\
( ^.^ )
 / >♪
```

```text
 /\_/\
( o.o )
 / >!!
```

```text
 /\_/\
( >.< )
 / >~!
```
